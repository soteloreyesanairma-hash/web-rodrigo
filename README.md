# PAGINA WEB - SAGUI-FASHION
- SAGUI-FASHION es una página web de una tienda de ropa que ofrece prendas modernas, cómodas y de buena - calidad. El objetivo es mostrar los productos, sus precios y permitir que los clientes registren sus - - pedidos mediante un formulario.
# ESTRUCTURA DEL PROYECTO
- css: Contiene las hojas de estilos
- images: contiene las imagenes a utilizar
- js: Contiene los archivos de JavaScript
- Test: contiene los archivos que no saldran
- Index.html: Contiene la pagina web (raiz)
# FUNCIONALIDADES
- Carrusel de imágenes de ropa.
- Sección de productos con imágenes y descripciones.
- Tabla con productos, tallas y precios.
- Formulario para registrar pedidos.
- Validación de campos obligatorios.
- Mensaje de confirmación del pedido con JavaScript.
- Menú de navegación entre las secciones de la página.
- Enlaces a redes sociales.
